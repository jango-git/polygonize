Низкополигональный редактор изображений в браузере. Загрузите фото, настройте триангуляцию, доработайте края модификаторами форм и экспортируйте результат в SVG или PNG.

**[РЕДАКТОР](https://jango-git.github.io/polygonize/)**

![Снимок экрана](../image.png)

## Возможности

- **Умная расстановка точек** - выборка по диску Пуассона методом Bridson с переменным радиусом, который задаётся детектором краёв Sobel: на краях радиус минимальный (плотные треугольники), на ровных участках - максимальный (разреженные треугольники). Генерация полностью детерминирована, поэтому один и тот же сид воспроизводит одинаковую сетку
- **Стек модификаторов** - неразрушающие слои ломаных, окружностей и кривых Catmull-Rom добавляют опорные рёбра поверх базовой сетки; меняйте их порядок и группируйте свободно перетаскиванием
- **Сэмплирование цвета** - средний или медианный цвет пикселей на треугольник; при желании - градиент по вершинам
- **Экспорт** - векторный SVG или PDF, либо растровый PNG, JPG или WebP вплоть до 4096px
- **Проекты** - сохраняйте и восстанавливайте работу в формате `.json`; сессия автоматически сохраняется в localStorage
- **Локализованный интерфейс** - 21 язык интерфейса, определяется автоматически из браузера и переключается в верхней панели

## Горячие клавиши

| Клавиша | Действие                             |
| ------- | ------------------------------------ |
| `~`     | Курсор (выделение)                   |
| `1`     | Инструмент «Ломаная»                 |
| `2`     | Инструмент «Кривая Catmull-Rom»      |
| `3`     | Окружность (центр и радиус)          |
| `4`     | Окружность (3 точки)                 |
| `Q`     | Переключить непрозрачность фона      |
| `W`     | Переключить непрозрачность точек     |
| `E`     | Переключить подсветку игл            |
| `F`     | Вписать изображение                  |
| `Space` | Применить незамкнутый путь           |
| `Esc`   | Отменить рисование / снять выделение |

## Разработка

```sh
npm install
npm run dev    # сервер разработки на http://localhost:3000
npm run build  # создаёт dist/bundle.js
```
