Браузерный редактор, позволяющий превратить фотографию в low-poly (картинку, собранную из треугольников). От обычных генераторов он отличается главным: помимо базовой сгенерированной сетки, ты сам можешь рисовать направляющие, и рёбра треугольников будут следовать вдоль них. Поэтому важные контуры - линия подбородка, оправа очков, силуэт - остаются чёткими, а не теряются в случайной сетке. Готовый результат можешь сохранить в вектор (SVG, PDF) или картинку (PNG, JPG, WebP).

## Что умеет

- **Направляющие, которые ты рисуешь сам.** Ведёшь линии, окружности, плавные кривые поверх изображения - и треугольники выстраиваются вдоль них. Это отдельные модификаторы поверх картинки, поэтому в любой момент их можно двигать, менять параметры детализации, группировать.
- **Сетка подстраивается под детали.** Там, где много мелочей и резких границ, треугольники мельче; на ровных участках вроде неба или фона - крупнее. Картинка выходит подробной там, где это нужно, и спокойной в остальном. При этом результат предсказуемо воспроизводим: с теми же настройками сетка получится точно такой же.
- **Автоматическая обводка как старт.** Чтобы не начинать с чистого листа, нажми "Обвести" - редактор сам найдёт края изображения и превратит их в редактируемые модификаторы, собранные в отдельную группу.
- **Цвет треугольников.** Каждый треугольник заливается средним цветом пикселей под ним - или медианным, если нужно приглушить яркие выбросы.
- **Экспорт.** Вектор (SVG, PDF) или растр (PNG, JPG, WebP) вплоть до 4096 пикселей.
- **Проекты.** Сохраняй работу в файл `.json` и возвращайся к ней позже. Но и текущая сессия восстанавливается сама, даже если ты просто закрыл вкладку.
- **Интерфейс на 21 языке.** Язык определяется по браузеру, переключается в верхней панели.

## Горячие клавиши

| Клавиша | Действие                                       |
| ------- | ---------------------------------------------- |
| `~`     | Курсор (выделение)                             |
| `1`     | Инструмент "Ломаная"                           |
| `2`     | Инструмент "Кривая"                            |
| `3`     | Окружность (центр и радиус)                    |
| `4`     | Окружность (3 точки)                           |
| `Q`     | Развернуть непрозрачность фона                 |
| `W`     | Развернуть непрозрачность точек                |
| `E`     | Развернуть непрозрачность тонких треугольников |
| `F`     | Центрировать изображение                       |
| `Space` | Завершить незамкнутый путь                     |
| `Esc`   | Отменить рисование / снять выделение           |

## Под капотом

Для любопытных: точки расставляются выборкой по диску Пуассона (алгоритм Bridson) с переменным радиусом - его задаёт карта границ Sobel, поэтому вдоль контуров сетка плотнее. Генерация детерминирована: один и тот же сид даёт одну и ту же сетку.
Весь тяжёлый геометрический пайплайн - карта границ, расстановка точек и сама триангуляция - собран в WASM-модуле на Rust. Цвет треугольников считается отдельно, в Web Worker.

## Разработка

```sh
npm run dev    # сервер разработки на http://localhost:3000
npm run build  # создаёт dist/bundle.js
```
