사진을 low-poly(삼각형으로 이루어진 그림)로 바꿔주는 브라우저 에디터예요. 흔한 생성기와의 가장 큰 차이는 이거예요. 자동으로 만들어진 기본 메시 위에, 직접 가이드를 그릴 수 있고 삼각형의 변이 그 선을 따라 정렬된다는 점이죠. 그래서 턱선, 안경테, 실루엣 같은 중요한 윤곽이 무작위 메시 속에 묻히지 않고 또렷하게 남아요. 완성한 결과는 벡터(SVG, PDF)나 이미지(PNG, JPG, WebP)로 저장할 수 있어요.

**[에디터 열기](https://jango-git.github.io/polygonize/)**

## 기능

- **직접 그리는 가이드.** 이미지 위에 직선, 원, 부드러운 곡선을 그리면 삼각형이 그것을 따라 정렬돼요. 이건 그림 위에 얹히는 독립적인 모디파이어(modifier)라서, 언제든 옮기거나 디테일 파라미터를 바꾸거나 그룹으로 묶을 수 있어요.
- **메시가 디테일에 맞춰 조정돼요.** 자잘한 요소와 날카로운 경계가 많은 곳에서는 삼각형이 더 작고, 하늘이나 배경처럼 평평한 부분에서는 더 커져요. 필요한 곳은 세밀하게, 나머지는 차분하게 표현되죠. 게다가 결과는 예측 가능하게 재현돼요. 같은 설정이면 메시도 똑같이 나와요.
- **삼각형의 색.** 각 삼각형은 그 아래 픽셀의 평균색으로 칠해져요. 너무 밝은 이상값을 누르고 싶다면 중앙값 색을 쓸 수도 있고요.
- **내보내기.** 벡터(SVG, PDF)나 래스터(PNG, JPG, WebP)로, 최대 4096px까지.
- **프로젝트.** 작업을 `.json` 파일로 저장해 두고 나중에 다시 이어갈 수 있어요. 그리고 그냥 탭을 닫았더라도 지금 세션은 알아서 복원돼요.
- **21개 언어 인터페이스.** 언어는 브라우저를 기준으로 자동 인식되고, 상단 패널에서 바꿀 수 있어요.

## 키보드 단축키

| 키      | 동작                          |
| ------- | ----------------------------- |
| `~`     | 커서(선택)                    |
| `1`     | "폴리라인" 도구               |
| `2`     | "곡선" 도구                   |
| `3`     | 원(중심과 반지름)             |
| `4`     | 원(3점)                       |
| `Q`     | 배경 불투명도 반전            |
| `W`     | 점 불투명도 반전              |
| `E`     | 가늘고 긴 삼각형 불투명도 반전 |
| `F`     | 이미지 가운데 맞추기          |
| `Space` | 열린 경로 마무리하기          |
| `Esc`   | 그리기 취소 / 선택 해제       |

## 내부 동작

궁금한 분들을 위해. 점은 포아송 디스크 샘플링(Bridson 알고리즘)으로 가변 반지름을 써서 배치돼요. 반지름은 Sobel 경계 맵이 정하기 때문에 윤곽을 따라 메시가 더 촘촘해지죠. 생성은 결정적이라서 같은 seed(시드)면 같은 메시가 나와요.
무거운 기하 파이프라인 전체, 즉 경계 맵, 점 배치, 그리고 삼각분할 자체는 Rust로 작성된 WASM 모듈에 모여 있어요. 삼각형의 색은 따로 Web Worker 안에서 계산돼요.

## 개발

```sh
npm install
npm run dev    # http://localhost:3000 에서 개발 서버 실행
npm run build  # dist/bundle.js 출력
```
