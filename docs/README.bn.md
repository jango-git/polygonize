ব্রাউজার-ভিত্তিক একটি লো-পলি ছবি সম্পাদক। একটি ছবি লোড করুন, ত্রিভুজায়ন সূক্ষ্ম করুন, আকৃতি মডিফায়ার দিয়ে প্রান্ত পরিমার্জন করুন এবং SVG বা PNG হিসেবে এক্সপোর্ট করুন।

## বৈশিষ্ট্য

- **স্মার্ট বিন্দু সিডিং** - Sobel প্রান্ত শনাক্তকরণে চালিত পরিবর্তনশীল ব্যাসার্ধসহ Bridson Poisson ডিস্ক স্যাম্পলিং: প্রান্তগুলো ছোট ন্যূনতম ব্যাসার্ধ পায় (ঘন ত্রিভুজ), সমতল এলাকা বড় সর্বোচ্চ ব্যাসার্ধ পায় (বিরল ত্রিভুজ)। তৈরি প্রক্রিয়া সম্পূর্ণরূপে সিডেড, তাই একটি নির্দিষ্ট সিড একই মেশ পুনরায় তৈরি করে
- **মডিফায়ার স্ট্যাক** - অ-ধ্বংসাত্মক পলিলাইন, বৃত্ত এবং Catmull-Rom কার্ভ স্তর বেস মেশের উপর সীমাবদ্ধতার প্রান্ত যোগ করে; ড্র্যাগ-অ্যান্ড-ড্রপ দিয়ে এগুলোকে স্বাধীনভাবে পুনর্বিন্যাস বা গ্রুপ করুন
- **রঙ নমুনায়ন** - প্রতি ত্রিভুজে গড় বা মধ্যমা পিক্সেল রঙ; ঐচ্ছিক প্রতি-শীর্ষবিন্দু গ্রেডিয়েন্ট
- **এক্সপোর্ট** - ভেক্টর SVG বা PDF, কিংবা র‍্যাস্টারাইজড PNG, JPG বা WebP, ৪০৯৬px পর্যন্ত
- **প্রকল্প** - কাজ `.json` হিসেবে সংরক্ষণ ও পুনরুদ্ধার করুন; সেশন স্বয়ংক্রিয়ভাবে localStorage-এ সংরক্ষিত হয়
- **স্থানীয়কৃত ইন্টারফেস** - ২১টি ইন্টারফেস ভাষা, ব্রাউজার থেকে স্বয়ংক্রিয়ভাবে শনাক্ত হয় এবং উপরের বারে পরিবর্তনযোগ্য

## কীবোর্ড শর্টকাট

| Key     | Action                        |
| ------- | ----------------------------- |
| `~`     | কার্সর (নির্বাচন)               |
| `1`     | পলিলাইন টুল                 |
| `2`     | Catmull-Rom কার্ভ টুল        |
| `3`     | বৃত্ত টুল (কেন্দ্র ও ব্যাসার্ধ) |
| `4`     | বৃত্ত টুল (৩ বিন্দু)            |
| `Q`     | পটভূমির অস্বচ্ছতা টগল করুন       |
| `W`     | বিন্দুর অস্বচ্ছতা টগল করুন         |
| `E`     | স্পাইক ওভারলে টগল করুন         |
| `F`     | ছবি ভিউতে মানানসই করুন          |
| `Space` | খোলা পাথ প্রয়োগ করুন           |
| `Esc`   | অঙ্কন বাতিল / নির্বাচন বাতিল করুন  |

## ডেভেলপমেন্ট

```sh
npm install
npm run dev    # http://localhost:3000-এ ডেভ সার্ভার
npm run build  # dist/bundle.js তৈরি করে
```
