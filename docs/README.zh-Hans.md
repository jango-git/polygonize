一款浏览器编辑器，能把照片变成 low-poly（由三角形拼成的画面）。它和普通的生成器有一个关键区别：除了自动生成的基础网格之外，你还可以亲手绘制引导线，三角形的边会沿着它们排列。这样一来，重要的轮廓，比如下巴的线条、眼镜框、人物剪影，都能保持清晰，而不会消失在随机的网格里。做好的成品可以导出为矢量图（SVG、PDF）或位图（PNG、JPG、WebP）。

**[打开编辑器](https://jango-git.github.io/polygonize/)**

## 功能

- **你亲手绘制的引导线。** 在图像上画出直线、圆、平滑曲线，三角形就会沿着它们排列。这些是叠加在图片之上的独立修改器（modifier），所以随时都能移动它们、调整细分参数、进行分组。
- **网格会自适应细节。** 在细节多、边界锐利的地方，三角形更小；在天空或背景这类平坦区域，三角形更大。需要的地方画面更精细，其余地方则更简洁。而且结果可以稳定复现：用同样的设置，得到的网格会完全一样。
- **自动描摹，作为起点。** 不必从一张白纸开始，点一下“描摹图像”，编辑器就会自己找出图像的边缘，把它们变成可编辑的修改器，并集中到一个独立的分组里。
- **三角形的颜色。** 每个三角形都用其下方像素的平均色填充，如果想抑制过亮的异常值，也可以改用中位色。
- **导出。** 矢量图（SVG、PDF）或位图（PNG、JPG、WebP），最大可达 4096 像素。
- **项目。** 把作品保存为 `.json` 文件，以后再回来继续。即使你只是关掉了标签页，当前会话也会自动恢复。
- **21 种语言界面。** 语言会根据浏览器自动判断，也可以在顶部面板里切换。

## 快捷键

| 按键    | 操作                   |
| ------- | ---------------------- |
| `~`     | 光标（选择）           |
| `1`     | 折线工具               |

| `3`     | 贝塞尔钢笔工具         |

| `W`     | 切换顶点不透明度       |

| `F`     | 图像适应视图           |
| `Space` | 应用开放路径           |
| `Esc`   | 取消绘制／取消选择     |

## 原理一窥

给好奇的人看：点是用泊松圆盘采样（Bridson 算法）以可变半径布置的，半径由 Sobel 边界图决定，所以沿着轮廓网格会更密。生成过程是确定性的：同一个 seed（随机种子）会得到同一张网格。
整条繁重的几何流水线，包括边界图、点的布置和三角剖分本身，都打包在用 Rust 编写的 WASM 模块里。三角形的颜色则单独计算，放在 Web Worker 中处理。
