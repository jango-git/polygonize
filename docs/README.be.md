Браўзерны рэдактар, які ператварае фотаздымак у low-poly - карцінку, сабраную з трохвугольнікаў. Ад звычайных генератараў ён адрозніваецца галоўным: паверх згенераванай сеткі ты сам малюеш накіроўвальныя, і рэбры трохвугольнікаў ідуць уздоўж іх. Важныя контуры - лінія падбародка, аправа акуляраў, сілуэт - застаюцца выразнымі, а не тонуць у выпадковай сетцы.

## Што ўмее

- **Накіроўвальныя, якія ты малюеш сам.** Вядзеш лініі, акружнасці, плаўныя крывыя паверх выявы - і трохвугольнікі выбудоўваюцца ўздоўж іх. Гэта асобныя мадыфікатары паверх карцінкі, таму ў любы момант іх можна рухаць, мяняць параметры дэталізацыі, групаваць.
- **Сетка падладжваецца пад дэталі.** Там, дзе шмат дробязяў і рэзкіх меж, трохвугольнікі драбнейшыя; на роўных участках накшталт неба ці фону - буйнейшыя. Выява выходзіць падрабязнай там, дзе гэта трэба, і спакойнай ва ўсім астатнім. Пры гэтым вынік прадказальна ўзнаўляецца: з тымі ж наладамі сетка атрымаецца дакладна такой жа.
- **Аўтаматычная абводка як старт.** Каб не пачынаць з чыстага ліста, націсні "Абвесці выяву" - рэдактар сам знойдзе краі выявы і ператворыць іх у рэдагуемыя мадыфікатары, сабраныя ў асобную групу.
- **Колер трохвугольнікаў.** Кожны трохвугольнік заліваецца сярэднім колерам пікселяў пад ім - або медыянным, калі трэба прыглушыць яркія выкіды.
- **Экспарт.** Вектар (SVG, PDF) або растр (PNG, JPG, WebP) аж да 4096 пікселяў.
- **Праекты.** Захоўвай працу ў файл `.json` і вяртайся да яе пазней. Ды і бягучая сесія аднаўляецца сама, нават калі ты проста закрыў укладку.
- **Інтэрфейс на 21 мове.** Мова вызначаецца паводле браўзера, пераключаецца ў верхняй панэлі.

## Пад капотам

Для дапытлівых: пункты расстаўляюцца выбаркай па дыску Пуасона (алгарытм Bridson) са зменным радыусам - яго задае карта меж Sobel, таму ўздоўж контураў сетка шчыльнейшая. Генерацыя дэтэрмінаваная: адзін і той жа seed дае адну і тую ж сетку.
Увесь цяжкі геаметрычны канвеер - карта меж, расстаноўка пунктаў і сама трыянгуляцыя - сабраны ў WASM-модулі на Rust. Колер трохвугольнікаў лічыцца асобна, у Web Worker.

Калі збіраешся чытаць зыходны код, пачні з [агляду архітэктуры](onboarding.be.md).

## Распрацоўка

```sh
npm install
npm run dev    # сервер распрацоўкі на http://localhost:3000
npm run build  # стварае dist/bundle.js
```
