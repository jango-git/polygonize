Нізкаполіганальны рэдактар выяў у браўзеры. Загрузіце фота, наладзьце трыянгуляцыю, удакладніце краі з дапамогай мадыфікатараў формаў, экспартуйце ў SVG або PNG.

## Магчымасці

- **Разумнае размяшчэнне кропак** - выбарка дыскам Пуасона Bridson са зменным радыусам, які кіруецца дэтэкцыяй краёў Sobel: краі атрымліваюць шчыльны мінімальны радыус (густыя трохвугольнікі), роўныя ўчасткі - вольны максімальны радыус (рэдкія трохвугольнікі). Генерацыя цалкам кіруецца зернем, таму адно і тое ж зерне ўзнаўляе тую самую сетку
- **Стос мадыфікатараў** - неразбуральныя слаі паліліній, акружнасцей і крывых Catmull-Rom дадаюць абмежавальныя краі па-над базавай сеткай; свабодна змяняйце іх парадак або групуйце перацягваннем
- **Выбарка колеру** - сярэдні або медыянны колер пікселяў на трохвугольнік; апцыянальны градыент па вяршынях
- **Экспарт** - вектарны SVG або PDF, ці растравы PNG, JPG або WebP да 4096px
- **Праекты** - захоўвайце і аднаўляйце працу як `.json`; сесія аўтаматычна захоўваецца ў localStorage
- **Лакалізаваны інтэрфейс** - 21 мова інтэрфейсу, аўтаматычна вызначаецца з браўзера і пераключаецца ў верхняй панэлі

## Спалучэнні клавіш

| Клавіша | Дзеянне                          |
| ------- | ------------------------------- |
| `~`     | Курсор (вылучэнне)              |
| `1`     | Інструмент паліліній            |
| `2`     | Інструмент крывой Catmull-Rom   |
| `3`     | Інструмент акружнасці (цэнтр і радыус) |
| `4`     | Інструмент акружнасці (3 кропкі) |
| `Q`     | Пераключыць непразрыстасць фону |
| `W`     | Пераключыць непразрыстасць кропак |
| `E`     | Пераключыць слой шыпоў          |
| `F`     | Упісаць выяву ў акно            |
| `Space` | Ужыць незамкнёны шлях           |
| `Esc`   | Скасаваць маляванне / зняць вылучэнне |

## Распрацоўка

```sh
npm install
npm run dev    # сервер распрацоўкі на http://localhost:3000
npm run build  # стварае dist/bundle.js
```
