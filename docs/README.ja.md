写真を三角形で構成されたロウポリ画像に変換する、ブラウザで動くエディターです。一般的な生成ツールとの一番の違いは、自動生成されたメッシュの上に自分でガイドを描けること - 三角形の辺はそのガイドに沿って並びます。あご先のライン、メガネのフレーム、シルエットといった重要な輪郭は、ランダムなメッシュに埋もれることなくくっきりと残ります。

**[エディターを開く](https://jango-git.github.io/polygonize/)**

![スクリーンショット](../image.png)

## できること

- **ガイド。** 画像の上に直線、円、なめらかな曲線を描くと、三角形がそれに沿って並びます。これは一度きりの操作ではなくモディファイアです - いつでも動かしたり、細かさを変えたり、グループ化したりできます。
- **細部に合わせて調整されるメッシュ。** 細かいディテールや輪郭がはっきりした部分では三角形が小さくなり、空のような平坦な領域では大きくなります。必要な部分は精細に、それ以外は落ち着いた仕上がりになります。
- **自動輪郭抽出。** 何もない状態から始めなくて済むよう、「輪郭抽出」を押すと、エディターが画像のエッジを見つけ、編集可能なモディファイアに変換して専用のグループにまとめてくれます。
- **三角形の色。** 各三角形は、その下にあるピクセルの平均色で塗りつぶされます。強い外れ値を抑えたい場合は中央値も選べます。
- **エクスポート。** ベクター（SVG、PDF）、またはラスター（PNG、JPG、WebP）を最大4096ピクセルまで書き出せます。
- **プロジェクト。** 作業内容を `.json` ファイルに保存して、あとで再開できます。現在のセッションはタブを閉じただけでも自動的に復元されます。
- **21言語対応のインターフェース。** 言語はブラウザから自動検出され、上部パネルで切り替えられます。

## 内部の仕組み

点の配置には、可変半径によるポアソンディスクサンプリング（Bridsonアルゴリズム）を使用しています。半径はSobelエッジマップによって決まるため、輪郭に沿ってメッシュが密になります。生成は決定的です - 同じシードは常に同じメッシュを生成します。エッジマップの計算、点の配置、三角形分割といった重い幾何計算パイプラインはすべて、Rustで書かれたWASMモジュールにまとめられています。三角形の色計算は、Web Worker上で別に行われます。

ソースコードを読むつもりなら、まず[アーキテクチャ概要](onboarding.ja.md)から始めてください。

## 開発

```sh
npm install
npm run dev    # 開発サーバー http://localhost:3000
npm run build  # dist/bundle.js を生成
```
