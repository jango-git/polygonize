# Polygonize

写真を low-poly（三角形を組み合わせた絵）に変換できるブラウザエディターです。よくあるジェネレーターとの一番の違いは、自動生成された基本メッシュに加えて、あなた自身がガイドを描けること。三角形の辺はそのガイドに沿って並びます。だから顎のラインやメガネのフレーム、シルエットといった大事な輪郭が、ランダムなメッシュに埋もれず、くっきり残ります。仕上がった結果はベクター（SVG、PDF）やラスター画像（PNG、JPG、WebP）として保存できます。

**[エディターを開く](https://jango-git.github.io/polygonize/)**

![スクリーンショット](../image.png)

## できること

- **自分で描くガイド。** 画像の上に直線や円、なめらかな曲線を引くと、三角形がそれに沿って並びます。これらは画像の上に重なる独立したモディファイア（modifier）なので、いつでも移動したり、ディテールのパラメーターを変えたり、グループ化したりできます。
- **メッシュがディテールに合わせて変化。** 細かいものや鋭い境界が多いところでは三角形が小さく、空や背景のような平らな部分では大きくなります。必要なところは精細に、それ以外は落ち着いた仕上がりに。しかも結果はきちんと再現できます。同じ設定なら、まったく同じメッシュになります。
- **三角形の色。** 各三角形は、その下にあるピクセルの平均色で塗られます。明るすぎる外れ値を抑えたいときは、中央値の色を使うこともできます。
- **エクスポート。** ベクター（SVG、PDF）またはラスター（PNG、JPG、WebP）で、最大 4096px まで。
- **プロジェクト。** 作業を `.json` ファイルに保存して、あとから再開できます。それに、ただタブを閉じただけでも、いまのセッションは自動で復元されます。
- **21 言語対応の UI。** 言語はブラウザから自動判定され、上部のパネルで切り替えられます。

## キーボードショートカット

| キー    | 操作                             |
| ------- | -------------------------------- |
| `~`     | カーソル（選択）                 |
| `1`     | 「折れ線」ツール                 |
| `2`     | 「曲線」ツール                   |
| `3`     | 円（中心と半径）                 |
| `4`     | 円（3 点）                       |
| `Q`     | 背景の不透明度を反転             |
| `W`     | 点の不透明度を反転               |
| `E`     | 針状の三角形の不透明度を反転     |
| `F`     | 画像を中央に合わせる             |
| `Space` | 開いたパスを確定する             |
| `Esc`   | 描画をキャンセル／選択を解除     |

## 仕組み

気になる方へ。点はポアソンディスクサンプリング（Bridson アルゴリズム）で、可変半径を使って配置されます。半径は Sobel の境界マップで決まるので、輪郭に沿ってメッシュは密になります。生成は決定的で、同じ seed（シード）なら同じメッシュになります。
重たい幾何処理のパイプライン全体、つまり境界マップ、点の配置、そして三角形分割そのものは、Rust で書かれた WASM モジュールにまとめられています。三角形の色は別に、Web Worker の中で計算されます。

## 開発

```sh
npm install
npm run dev    # http://localhost:3000 で開発サーバーを起動
npm run build  # dist/bundle.js を出力
```
