# Polygonize

[en](../README.md) · [zh-Hans](README.zh-Hans.md) · [hi](README.hi.md) · [es](README.es.md) · [fr](README.fr.md) · [bn](README.bn.md) · [pt](README.pt.md) · [ru](README.ru.md) · [id](README.id.md) · [de](README.de.md) · [ja](README.ja.md) · [tr](README.tr.md) · [vi](README.vi.md) · [ko](README.ko.md) · [it](README.it.md) · [pl](README.pl.md) · **uk** · [uz](README.uz.md) · [az](README.az.md) · [kk](README.kk.md) · [be](README.be.md)

Браузерний редактор, який дає змогу перетворити фотографію на low-poly (зображення, складене з трикутників). Від звичайних генераторів його відрізняє головне: окрім базової згенерованої сітки, ти й сам можеш малювати напрямні, і ребра трикутників ітимуть уздовж них. Тому важливі контури - лінія підборіддя, оправа окулярів, силует - лишаються чіткими, а не губляться у випадковій сітці. Готовий результат можна зберегти у вектор (SVG, PDF) або картинку (PNG, JPG, WebP).

## Можливості

- **Напрямні, які ти малюєш сам.** Ведеш лінії, кола, плавні криві поверх зображення - і трикутники вишиковуються вздовж них. Це окремі модифікатори поверх картинки, тож будь-якої миті їх можна рухати, змінювати параметри деталізації, групувати.
- **Сітка підлаштовується під деталі.** Там, де багато дрібниць і різких меж, трикутники дрібніші; на рівних ділянках на кшталт неба чи фону - більші. Зображення виходить детальним там, де це потрібно, і спокійним в усьому іншому. При цьому результат передбачувано відтворюється: з тими самими налаштуваннями сітка вийде точнісінько такою ж.
- **Колір трикутників.** Кожен трикутник заливається середнім кольором пікселів під ним - або медіанним, якщо треба приглушити яскраві викиди.
- **Експорт.** Вектор (SVG, PDF) або растр (PNG, JPG, WebP) аж до 4096 пікселів.
- **Проєкти.** Зберігай роботу у файл `.json` і повертайся до неї згодом. Та й поточна сесія відновлюється сама, навіть якщо ти просто закрив вкладку.
- **Інтерфейс 21 мовою.** Мова визначається за браузером, перемикається у верхній панелі.

## Гарячі клавіші

| Клавіша | Дія                                              |
| ------- | ------------------------------------------------ |
| `~`     | Курсор (виділення)                               |
| `1`     | Інструмент "Ламана"                              |
| `2`     | Інструмент "Крива"                               |
| `3`     | Коло (центр і радіус)                            |
| `4`     | Коло (3 точки)                                   |
| `Q`     | Інвертувати непрозорість фону                    |
| `W`     | Інвертувати непрозорість точок                   |
| `E`     | Інвертувати підсвічування вироджених трикутників |
| `F`     | Відцентрувати зображення                         |
| `Space` | Завершити незамкнений шлях                       |
| `Esc`   | Скасувати малювання / зняти виділення            |

## Під капотом

Для допитливих: точки розставляються вибіркою за диском Пуассона (алгоритм Bridson) зі змінним радіусом - його задає карта меж Sobel, тому вздовж контурів сітка щільніша. Генерація детермінована: один і той самий seed дає одну й ту саму сітку.
Увесь важкий геометричний конвеєр - карта меж, розставлення точок і сама тріангуляція - зібраний у WASM-модулі на Rust. Колір трикутників рахується окремо, у Web Worker.
