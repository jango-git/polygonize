Низькополігональний редактор зображень для браузера. Завантажте фото, налаштуйте тріангуляцію, уточніть краї за допомогою модифікаторів форм і експортуйте у SVG або PNG.

**[РЕДАКТОР](https://jango-git.github.io/polygonize/)**

![Знімок екрана](../image.png)

## Можливості

- **Розумне розсіювання точок** - вибірка диском Пуассона за алгоритмом Bridson зі змінним радіусом, що визначається детектором країв Sobel: краї отримують щільний мінімальний радіус (густі трикутники), а рівні ділянки - вільний максимальний радіус (розріджені трикутники). Генерація повністю керується сідом, тож той самий сід відтворює ту саму сітку
- **Стек модифікаторів** - неруйнівні шари ламаних, кіл і кривих Catmull-Rom додають обмежувальні краї поверх базової сітки; вільно змінюйте їхній порядок або групуйте перетягуванням
- **Вибірка кольору** - середній або медіанний колір пікселів на трикутник; за бажанням градієнт по вершинах
- **Експорт** - векторний SVG чи PDF або растровий PNG, JPG чи WebP до 4096px
- **Проєкти** - зберігайте й відновлюйте роботу як `.json`; сесія автоматично зберігається в localStorage
- **Локалізований інтерфейс** - 21 мова інтерфейсу з автовизначенням за браузером і перемиканням на верхній панелі

## Гарячі клавіші

| Клавіша | Дія                                   |
| ------- | ------------------------------------- |
| `~`     | Курсор (вибір)                        |
| `1`     | Інструмент ламаної                    |
| `2`     | Інструмент кривої Catmull-Rom         |
| `3`     | Інструмент кола (центр і радіус)      |
| `4`     | Інструмент кола (3 точки)             |
| `Q`     | Перемкнути непрозорість тла           |
| `W`     | Перемкнути непрозорість точок         |
| `E`     | Перемкнути накладання шипів           |
| `F`     | Вписати зображення у вікно            |
| `Space` | Застосувати незамкнений шлях          |
| `Esc`   | Скасувати малювання / зняти виділення |

## Розробка
