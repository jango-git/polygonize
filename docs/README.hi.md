ब्राउज़र में चलने वाला लो-पॉली इमेज एडिटर। कोई फ़ोटो लोड करें, त्रिभुजन को व्यवस्थित करें, शेप मॉडिफ़ायर से किनारों को सँवारें, और SVG या PNG के रूप में एक्सपोर्ट करें।

**[एडिटर](https://jango-git.github.io/polygonize/)**

![स्क्रीनशॉट](../image.png)

## विशेषताएँ

- **स्मार्ट पॉइंट सीडिंग** - Sobel किनारा पहचान से नियंत्रित परिवर्तनशील त्रिज्या के साथ Bridson Poisson डिस्क सैंपलिंग: किनारों को छोटी न्यूनतम त्रिज्या मिलती है (सघन त्रिभुज), जबकि समतल क्षेत्रों को बड़ी अधिकतम त्रिज्या (विरल त्रिभुज)। जनरेशन पूरी तरह सीडेड है, इसलिए एक ही सीड हर बार वही मेश बनाती है
- **मॉडिफ़ायर स्टैक** - नॉन-डिस्ट्रक्टिव पॉलीलाइन, सर्कल और Catmull-Rom कर्व लेयर बेस मेश के ऊपर कंस्ट्रेंट किनारे जोड़ती हैं; इन्हें ड्रैग-एंड-ड्रॉप से स्वतंत्र रूप से पुनः क्रमबद्ध या समूहबद्ध करें
- **रंग सैंपलिंग** - प्रति त्रिभुज औसत या मध्यिका पिक्सेल रंग; वैकल्पिक प्रति-वर्टेक्स ग्रेडिएंट
- **एक्सपोर्ट** - वेक्टर SVG या PDF, या रास्टराइज़्ड PNG, JPG या WebP 4096px तक
- **प्रोजेक्ट** - काम को `.json` के रूप में सहेजें और पुनः लोड करें; सत्र अपने आप localStorage में सहेजा जाता है
- **लोकलाइज़्ड UI** - 21 इंटरफ़ेस भाषाएँ, ब्राउज़र से अपने आप पहचानी जाती हैं और टॉप बार में बदली जा सकती हैं

## कीबोर्ड शॉर्टकट

| कुंजी   | क्रिया                           |
| ------- | -------------------------------- |
| `~`     | कर्सर (चुनें)                    |
| `1`     | पॉलीलाइन टूल                     |
| `2`     | Catmull-Rom कर्व टूल             |
| `3`     | सर्कल टूल (केंद्र और त्रिज्या)   |
| `4`     | सर्कल टूल (3 पॉइंट)              |
| `Q`     | बैकग्राउंड अपारदर्शिता टॉगल करें |
| `W`     | पॉइंट अपारदर्शिता टॉगल करें      |
| `E`     | स्पाइक ओवरले टॉगल करें           |
| `F`     | इमेज को व्यू में फ़िट करें       |
| `Space` | खुला पथ लागू करें                |
| `Esc`   | ड्रॉइंग रद्द करें / चयन हटाएँ    |

## डेवलपमेंट

```sh
npm install
npm run dev    # http://localhost:3000 पर डेव सर्वर
npm run build  # dist/bundle.js आउटपुट करता है
```
