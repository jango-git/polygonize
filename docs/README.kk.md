Фотосуретті low-poly бейнеге (үшбұрыштардан жинақталған суретке) айналдыруға мүмкіндік беретін браузерлік редактор. Әдеттегі генераторлардан оны бастысы ерекшелейді: базалық генерацияланған тордан бөлек, сен бағыттаушыларды өзің де сыза аласың, ал үшбұрыш қырлары солардың бойымен жүреді. Сондықтан маңызды контурлар - иек сызығы, көзілдірік жақтауы, силуэт - кездейсоқ торда жоғалмай, анық күйінде қалады. Дайын нәтижені векторға (SVG, PDF) немесе суретке (PNG, JPG, WebP) сақтай аласың.

## Не істей алады

- **Өзің сызатын бағыттаушылар.** Бейненің үстінен сызықтарды, шеңберлерді, біркелкі қисықтарды жүргізесің - үшбұрыштар солардың бойымен тізіледі. Бұл - суреттің үстіндегі жеке модификаторлар, сондықтан кез келген сәтте оларды жылжытуға, детализация параметрлерін өзгертуге, топтауға болады.
- **Тор детальдарға бейімделеді.** Ұсақ-түйек пен өткір шекаралар көп жерде үшбұрыштар ұсақ; аспан немесе фон сияқты тегіс аймақтарда - ірі. Сурет қажет жерінде егжей-тегжейлі, қалғанында байсалды болып шығады. Сонымен қатар нәтиже болжамды түрде қайталанады: дәл сол баптаулармен тор тура сондай болып шығады.
- **Бастау үшін автоматты бағдарлау.** Бос парақтан бастамау үшін "Суретті бағдарлау" түймесін бас - редактор бейненің жиектерін өзі тауып, оларды өңделетін модификаторларға айналдырып, бөлек топқа жинайды.
- **Үшбұрыш түсі.** Әр үшбұрыш астындағы пиксельдердің орташа түсімен боялады - немесе жарық шектен шығуларды басу қажет болса, медианалық түсімен.
- **Экспорт.** Вектор (SVG, PDF) немесе растр (PNG, JPG, WebP) 4096 пиксельге дейін.
- **Жобалар.** Жұмысыңды `.json` файлына сақтап, оған кейін орала аласың. Оның үстіне ағымдағы сессия, тіпті қойындыны жай жапсаң да, өзі қалпына келеді.
- **21 тілдегі интерфейс.** Тіл браузер бойынша анықталады, жоғарғы панельден ауыстырылады.

## Жылдам пернелер

| Перне   | Әрекет                                          |
| ------- | ----------------------------------------------- |
| `~`     | Курсор (бөлектеу)                                |
| `1`     | "Сынық сызық" құралы                             |
| `2`     | "Қисық" құралы                                   |
| `3`     | Шеңбер (центр және радиус)                       |
| `4`     | Шеңбер (3 нүкте)                                 |
| `Q`     | Фон мөлдірлігін кері аудару                      |
| `W`     | Нүктелер мөлдірлігін кері аудару                 |
| `E`     | Азғындаған үшбұрыштардың айқындалуын кері аудару |
| `F`     | Бейнені ортаға қою                               |
| `Space` | Тұйықталмаған жолды аяқтау                       |
| `Esc`   | Сызуды болдырмау / бөлектеуді алып тастау        |

## Капот астында

Қызыққандар үшін: нүктелер Пуассон дискі бойынша іріктеумен (Bridson алгоритмі) айнымалы радиуспен орналастырылады - оны Sobel шекаралар картасы береді, сондықтан контурлар бойымен тор тығызырақ. Генерация детерминирленген: бір seed бір ғана тор береді.
Бүкіл ауыр геометриялық конвейер - шекаралар картасы, нүктелерді орналастыру және триангуляцияның өзі - Rust тіліндегі WASM модуліне жинақталған. Үшбұрыш түсі бөлек, Web Worker ішінде есептеледі.

## Әзірлеу

```sh
npm install
npm run dev    # әзірлеу сервері http://localhost:3000 мекенжайында
npm run build  # dist/bundle.js файлын жасайды
```
