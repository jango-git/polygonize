Браузерде жұмыс істейтін төмен полигонды сурет редакторы. Фотоны жүктеңіз, триангуляцияны баптаңыз, пішін модификаторларымен шеттерді нақтылаңыз, SVG не PNG етіп экспорттаңыз.

**[РЕДАКТОР](https://jango-git.github.io/polygonize/)**

![Скриншот](../image.png)

## Мүмкіндіктер

- **Нүктелерді ақылды орналастыру** - Sobel шеттерін анықтауға негізделген өзгермелі радиусы бар Bridson Poisson дискі бойынша таңдау: шеттер ең аз радиус алады (тығыз үшбұрыштар), жазық аймақтар ең үлкен радиус алады (сирек үшбұрыштар). Генерация толықтай тұқымдалған, сондықтан бірдей тұқым бірдей торды қайта жасайды
- **Модификаторлар стегі** - Сынық сызық, шеңбер және Catmull-Rom қисығы қабаттары негізгі торға бұзбай шектеу шеттерін қосады; оларды сүйреп апару арқылы еркін реттеңіз немесе топтаңыз
- **Түсті алу** - Әр үшбұрыш бойынша пикселдердің орташа не медианалық түсі; қосымша әр төбе бойынша градиент
- **Экспорт** - Векторлық SVG не PDF, немесе 4096px-ге дейін растрланған PNG, JPG не WebP
- **Жобалар** - Жұмысты `.json` ретінде сақтаңыз және қалпына келтіріңіз; сеанс localStorage-қа автоматты сақталады
- **Локализацияланған интерфейс** - 21 интерфейс тілі, браузерден автоматты анықталады әрі жоғарғы жолақтан ауыстырылады

## Жылдам пернелер

| Перне   | Әрекет                                  |
| ------- | --------------------------------------- |
| `~`     | Меңзер (таңдау)                         |
| `1`     | Сынық сызық құралы                      |
| `2`     | Catmull-Rom қисық құралы                |
| `3`     | Шеңбер құралы (центр және радиус)       |
| `4`     | Шеңбер құралы (3 нүкте)                 |
| `Q`     | Фон мөлдірлігін ауыстыру                |
| `W`     | Нүкте мөлдірлігін ауыстыру              |
| `E`     | Шип қабатын ауыстыру                    |
| `F`     | Суретті көрініске сыйдыру               |
| `Space` | Ашық жолды қолдану                      |
| `Esc`   | Сызуды болдырмау / таңдауды алып тастау |

## Әзірлеу

```sh
npm install
npm run dev    # http://localhost:3000 мекенжайындағы әзірлеу сервері
npm run build  # dist/bundle.js файлын шығарады
```
